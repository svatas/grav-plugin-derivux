# Derivux by Gravister

**Derivux by Gravister** is a Grav 2 plugin for creating and maintaining minimal derived themes using Grav's native theme inheritance.

The project is intentionally starting small. Version **0.1.0** establishes the repository, project governance and a minimal loadable Grav plugin. Theme derivation/generation is not implemented yet.

## Goals

- create minimal derived themes instead of copying whole parent themes;
- preserve Grav-native theme inheritance;
- keep generated themes understandable and maintainable;
- avoid unnecessary duplication of parent-theme files;
- provide a safe foundation for future Gravister tooling.

## Status

Early development. Current bootstrap version: **0.1.0**.

See `DERIVUX-STATE.md` for the authoritative project state.

## Requirements

- Grav 2.x
- PHP compatible with the target Grav 2 installation
